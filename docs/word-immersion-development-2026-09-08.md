# 词浸开发交付 · 2026-09-08

本轮完成现有测试版的阅读、复习与失败恢复闭环，并完成真实模型和浏览器验收。未变更公开上架状态或积分定价。

## 已实现

- 阅读器：章节目录、原文对照、16–30px 字号调节、单词释义与浏览器发音。
- 阅读记录：打开章节记一次遇词，重复打开不重复累计；明确标记本章读完后更新进度，跳到末章不会把其他章节自动标为已读。
- 词汇：搜索、状态筛选、到期复习；先回忆，再显示释义和原文语境，按还不熟/已掌握安排次日/7日复习。
- 生成失败：复用原文草稿，相同设置跳过已完成章节；原有任务退款机制保持幂等。重试是新的计费任务，页面显示费用。
- 生成前检查：未配置或未开启托管模型时不预扣积分，前台显示生成服务未就绪。
- 长文：去掉原先16章静默截断，拆分过长段落，保留章节标题。
- 目标词：按章节原文语义线索和学习状态挑选至多160个候选，避免始终只使用词库排序前160词。
- 窄屏：恢复阅读入口和词汇操作按钮；保留可读标签及键盘焦点提示。
- 内置词库按实际数量标为示例词库，不声称覆盖完整考试词表。

- 390px宽度下页面与阅读器无横向溢出，核心操作仍存在；测试后恢复桌面视口。

联调发现并修复模型网关null输出预算被转换成64的默认值缺陷。词浸显式请求4096上限，对支持的通义模型关闭额外思考。早期中转调用虽返回成功但内容未通过结构校验，不将这些调用算为成功生成。

生成策略改为：模型只提出原文精确替换片段，程序拼接未修改原文。只接受词库内目标词，禁止重叠、不存在或涉及数字的片段。不能据此保证所有语义选择100%正确，仍保留原文对照与测试版提示。
