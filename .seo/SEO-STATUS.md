# OneShowSEO Status

## Current status

The product now has a real read-only discovery and commercial accounting loop.
CMS execution is available only through a tested owner-configured webhook and
stays visibly unconnected otherwise.

## Data limitations

Search Console, GA4, Baidu, CMS, traffic, conversion, and ranking data are not
authorized in this environment. The UI does not infer or fabricate them.

## Next checkpoint

Connect one production-owned CMS test site, perform an apply/rollback canary,
then add OAuth connectors for first-party performance measurement.
