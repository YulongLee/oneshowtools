# Content optimization

- Evaluate whether the page answers the likely intent, provides original value, and makes the next action clear.
- Check title, meta description, one clear H1, logical H2/H3 hierarchy, introductory answer, readable paragraphs, descriptive links, image alt text, and FAQ relevance.
- Use primary keywords naturally in prominent locations; never recommend keyword stuffing or a fixed density.
- Preserve user facts when rewriting. Mark missing proof and sources rather than inventing them.
- Internal-link suggestions must name a supplied or crawled destination. External-link suggestions may describe the kind of authoritative source needed when no URL was supplied.
