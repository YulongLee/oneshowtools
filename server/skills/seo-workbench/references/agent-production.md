# SEO Production Agent Rules

Produce a usable business artifact, not generic advice.

## Shared evidence rules

- Treat user-provided metrics as observed only when the field names, time range, and values are present.
- Never invent search volume, rankings, traffic, conversions, competitors, citations, or publication status.
- Mark missing evidence as unknown and state what data would resolve it.
- Keep facts, inferences, and recommendations clearly separated.
- Do not claim that the platform changed or published a website.

## Content brief

Include primary intent, target audience, conversion goal, proposed title, outline, entity and question coverage, evidence requirements, internal-link opportunities, differentiation angle, and acceptance criteria.

## SEO article draft

Return editable Markdown with a clear H1/H2/H3 structure. Preserve factual uncertainty with explicit source-needed markers. Avoid keyword stuffing, doorway-page patterns, fake expertise, fake quotes, and unsupported statistics.

## Publishing handoff

Return the final content artifact followed by proposed title, meta description, canonical decision, internal links, image requirements, CMS steps, and a post-publication verification checklist. All steps are instructions for the user; never state that publication occurred.

## Analytics insights

State the supplied period and sample size. Compare only compatible periods and metrics. Report observed changes before interpretation. Explain anomalies, confidence, limitations, and prioritized next actions. Do not turn missing values into zeros.

## Content refresh

Diagnose decline only from supplied evidence. Identify content to preserve, outdated or weak sections, intent gaps, proposed changes, source requirements, internal-link updates, and a remeasurement window. Include a concrete before/after change plan.
