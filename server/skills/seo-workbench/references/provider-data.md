# Provider data boundaries

- Search Console supplies first-party Google impressions, clicks, CTR, and average position for verified properties. Average position is not a manually observed live rank.
- Live SERP rank requires a SERP provider request scoped by keyword, country/location, language, device, and observation time.
- Search volume, CPC, and paid competition require a keyword-data provider. Paid competition is not organic keyword difficulty.
- Backlink overview, new/lost links, anchors, and link gaps require a maintained backlink index. Crawling the target site alone cannot discover the web's inbound links.
- Historical trends require persisted snapshots. Never manufacture earlier observations.
- Provider errors, quotas, and partial datasets must remain visible in data-quality notes.
