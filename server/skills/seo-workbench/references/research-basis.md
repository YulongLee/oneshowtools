# Research basis

Rules were distilled from primary documentation consulted on 2026-08-01:

- Google Search Central: Search Essentials, people-first content, sitemaps, robots directives, canonicalization, and duplicate URL consolidation.
- Google Search Console API: Search Analytics query dimensions, filters, limitations, and metric definitions.
- Google PageSpeed Insights API v5: Lighthouse-based performance, accessibility, best-practices, and SEO categories.
- DataForSEO API v3: live SERP, keyword data, and backlink endpoints and their paid-provider boundaries.
- SEOnaut, Unlighthouse, Google Lighthouse, and SerpBear: issue severity, bounded crawl sampling, structured reports, and persisted ranking observations.

Re-check provider versions and deprecations before changing integrations.
