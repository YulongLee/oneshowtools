# Keyword research

- Classify intent as informational, navigational, commercial, or transactional, and briefly explain why.
- Generate seed, long-tail, question, comparison, alternative, and problem-solution variants from the supplied product/topic/audience.
- Cluster by shared search task, not only lexical similarity. Give every cluster one primary page intent.
- Opportunity score is a transparent heuristic unless a provider returns volume and competition. State the formula and label it `heuristic`.
- A model-generated keyword is an idea, not evidence of demand. Search volume, CPC, difficulty, and current SERP rank remain null without a connected source.
